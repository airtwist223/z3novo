# Как выпускать версию (для сопровождающего)

## Нумерация
- `T1`, `T2`, … — публичные тестовые версии. `1.0` — первая стабильная, дальше `1.1`, `1.2`…
- Метка версии вшивается в приложение и видна в его заголовке (до 15 символов: буквы, цифры, `.`, `_`, `-`).
- Файл образа: `Z3NOVO_<версия>.bin` (16 МБ).

## Что лежит в репозитории
- Описание, документы, история версий, скрипты для тестеров (`tools/`).
- В `releases/<версия>/` — только `SHA256SUMS`. Сами образы в git не кладутся: их прикладывают к выпуску отдельно.

## Перед выпуском
1. Образ собран из проверенных компонентов, проверка образа прошла.
2. В образе нет личных данных: серийников, UUID, MAC, ключа Windows, данных fTPM и тренировки памяти.
   Раздаётся только чистый собранный образ, никогда не чтение с чьей-то платы.
3. Тексты приложения вычитаны: понятны любому, RU и EN совпадают, без внутренних кодов.
4. Тесты приложения в эмуляторе прошли.
5. Версия проверена на плате: запуск, перезагрузки, обновление с флешки, отчёт для диагностики.
6. В `CHANGELOG.md` запись о версии: что есть, что изменилось, ограничения, что проверено и что нет.
7. `SHA256SUMS` в `releases/<версия>/`, коммит, метка `git tag <версия>`.
